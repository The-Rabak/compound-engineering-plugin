Add a dark-mode toggle to the settings page

  4. Resolved Questions

Why

Users working at night keep the app open in a bright white window with no way to dim it, and repeatedly ask support how to fix "the blinding white screen."

As a night-shift user, I need a dark-mode toggle in Settings, so that I can use the app comfortably at night, because currently the interface is fixed to a bright theme which causes eye strain and repeated support requests.

Chosen Approach

Add a three-state toggle (System / Light / Dark) backed by a single CSS custom-property layer already used elsewhere in the app, persisted to the user's existing preferences record — no new storage mechanism, no new design tokens.

Also considered

A pure OS-preference-only mode (rejected: users without OS-level dark mode support, e.g. older browsers, would have no way to opt in).

Key Decisions

  1. Persist the choice to the user's preferences record, not localStorage.

    Keeps the setting consistent across devices, matching every other Settings-page preference.

  2. Default new users to "System" rather than "Light."

    Respects the OS-level signal the user already set instead of silently overriding it.

Resolved Questions

Should the toggle also change marketing/logged-out pages?
No — deferred; this brainstorm covers the authenticated Settings experience only.
Does this require a new design token set?
No — reuses the existing token layer; only the default values per theme change.

Success Criteria

  • A user can switch between System, Light, and Dark from Settings without a page reload.
  • The chosen theme persists across sessions and devices.

Scope

In scope

Settings toggle, preference persistence, existing token-layer dark values.

Deferred

Marketing/logged-out pages, per-page theme overrides, a scheduled auto-switch by time of day.

Stakeholder Impact

End users

Fewer eye-strain complaints; a long-requested preference.

Support

Fewer "blinding white screen" tickets.

Design

No new tokens; the existing dark values finally get a first-class entry point.
